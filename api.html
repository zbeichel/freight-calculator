What it does

Your software sends us a lane — pickup, delivery, trailer, weight — and gets back a quote: miles, rate per mile, total and a full breakdown. It's the same calculation as the calculator, with this month's rates, so the API and the website always agree.

Common uses: a "Get a quote" form on your own website, suggested rates inside your TMS, or pricing a list of lanes from a spreadsheet or database.

The API plan is $199.99/month and includes everything in Pro Max on the website, plus 5,000 API quotes with automatic miles every billing month. Requests where you send your own miles don't count toward the 5,000.

Getting started
  1. Get the API plan. Already subscribed? Choose API under Subscription on your Profile. New here? Sign up for the API plan.
  2. Create a key. Profile → API Access → Create key. Copy it right away; it's shown only once. You can have up to 5 keys and revoke any of them.
  3. Call the API from your server with the key in the Authorization header, as in the examples below.

Keep your key on your server. Store it in an environment variable or secrets manager. Never put it in a web page, a mobile app or a public code repository: anyone who has it can use up your quotes. The API doesn't accept calls made directly from a browser on another website for the same reason.

Request
POST https://quickfreightcalc.com/api/v1/quote
Authorization: Bearer qfc_live_…
Content-Type: application/json

Send a JSON object. Only origin and destination are required; everything else defaults to what a first visit to the calculator uses.

FieldTypeWhat it does
origintext, requiredPickup: a city and state ("Lancaster, PA"), a ZIP code or a street address. With your own miles, include the state so we can use that region's rates; without one we use national rates.
destinationtext, requiredDelivery, in the same formats.
milesnumberYour own miles (1–10,000). Leave it out and we look up driving miles with Google; that counts toward your 5,000 a month.
trailertextvan (default), reefer or flatbed.
weightnumberPounds. Under 10,000: ×0.95 · 10,000–29,999: ×0.97 · 30,000–44,000: ×1.00 · over 44,000: ×1.08. Leave it out for ×1.00.
commoditytextstandard (default), food, hazmat, highval or oversized.
pickupDatedateYYYY-MM-DD. Used by season and extraDayRate.
deliveryDatedateYYYY-MM-DD. With extraDayRate, adds a charge for days beyond normal transit (about 500 miles a day).
marginnumberYour margin in percent, 0–100. Default 15.
ratestextsheet: your own rate sheet from your Profile page, for the pickup state's region (where your sheet is blank, this month's market rate). The default once you've saved a rate sheet. regional: this month's market rate for the pickup state's region (the default without a rate sheet). national: the national market rate.
baseRatePerMilenumberYour own base rate in dollars per mile, used instead of ours.
dieselPricenumberDiesel in dollars per gallon. Adds a fuel surcharge of (price − $1.25) ÷ 6.5 per mile.
capacitytrue / falseAdjust for this month's load-to-truck ratio (up to ±12%). Default false.
seasontextA seasonal profile, by pickup month: fl, se, ca, pnw, tx, az, gl, ne_produce, storage, mw, ne, sw, national. Same list as the calculator's Seasonality setting.
holidayslistAny of roadcheck, brake_week, memorial, july4, labor, thanksgiving, xmas_nye, mothers_day.
marketnumberMarket adjustment in percent, −10 to 30. Default 0.
extraDayRatenumberDollars per extra transit day, when both dates are sent.

Field names are case-sensitive, and unknown fields are rejected so a typo can't quietly change a quote. Numbers can be sent as numbers or numeric strings.

Examples

curl

curl https://quickfreightcalc.com/api/v1/quote \
  -H "Authorization: Bearer $QFC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "Lancaster, PA",
    "destination": "New York, NY",
    "trailer": "reefer",
    "weight": 42000,
    "commodity": "food",
    "pickupDate": "2026-11-20"
  }'

JavaScript (Node.js)

// Node.js 18 or newer, on your server
const resp = await fetch('https://quickfreightcalc.com/api/v1/quote', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.QFC_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    origin: 'Lancaster, PA',
    destination: 'New York, NY',
    trailer: 'reefer',
    weight: 42000,
  }),
});
const data = await resp.json();
if (!resp.ok) throw new Error(data.error.message);
console.log(data.quote.total, data.lane.miles);

Python

import os
import requests

resp = requests.post(
    "https://quickfreightcalc.com/api/v1/quote",
    headers={"Authorization": f"Bearer {os.environ['QFC_API_KEY']}"},

        "origin": "Lancaster, PA",
        "destination": "New York, NY",

        "weight": 42000,
    },
    timeout=15,

data = resp.json()
if resp.status_code != 200:
    raise RuntimeError(data["error"]["message"])
print(data["quote"]["total"], data["lane"]["miles"])

Limits
  • 5,000 quotes with automatic miles per billing month. A request counts when we look up miles, including repeat requests for the same lane and lookups where a place or route can't be found. It doesn't count if the lookup fails on our side. Requests with your own miles never count.
  • 60 requests per minute per account, across all your keys.
  • Your Profile page shows this month's usage and when it resets, and every response includes usage.
  • If you reach 5,000, requests for automatic miles return 429 monthly_limit until your next billing month; requests with your own miles keep working.
A quote form on your website

Your web page can't call the API directly, because that would expose your key. Instead, the page sends the lane to your own server, your server asks us for the quote, and your server sends the price back to the page:

Visitor's browser→Your server (holds the key)→QuickFreightCalc API
// Your server (Node.js + Express). Your web page's quote form posts
// { origin, destination } here; the key never leaves your server.
app.post('/get-quote', async (req, res) => {
  const resp = await fetch('https://quickfreightcalc.com/api/v1/quote', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.QFC_API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      origin: String(req.body.origin || ''),
      destination: String(req.body.destination || ''),
      trailer: 'van',
      margin: 20, // your markup
    }),
  });
  const data = await resp.json();
  if (!resp.ok) return res.status(400).json({ message: data.error.message });
  res.json({ price: data.quote.total, miles: data.lane.miles });
});

A public form spends your monthly allowance for every visitor's lookup. Consider a CAPTCHA, a limit on how often one visitor can ask, or offering the form only to signed-in customers.

How quotes are figured

Exactly like the calculator:

adjusted rate/mile = base rate × weight × distance × commodity × capacity × season × holidays × market
cost               = (adjusted rate/mile + fuel surcharge/mile) × miles
total              = (cost + extra-day charge) × (1 + margin)
  • Base rate: this month's rate for the trailer type in the pickup state's region (Northeast, Southeast, Midwest, Southwest, West), or the national rate. ratesUpdated says which month's rates were used. Once you've saved a rate sheet on your Profile page, your own rate for the region (or your all-regions rate) is used instead, and the market rate only where your sheet is blank. breakdown.rateSource says which: sheet, market or provided (baseRatePerMile in the request).
  • Distance: short hauls cost more per mile and long hauls less, on the same curves the calculator uses.
  • Defaults: no fuel surcharge, capacity, seasonality or holidays, a 0% market adjustment and a 15% margin, the same as a first visit to the calculator.
Showing quotes
  • Quotes are estimates, not guaranteed rates. See section 3 of the Terms.
  • Automatic miles and drive times come from Google Maps. If you show them to anyone outside your company, credit Google Maps; the attribution field has text you can use.
  • Use the API to quote freight. Don't store or resell the miles, drive times or locations on their own. The full rules are in section 6 of the Terms.
